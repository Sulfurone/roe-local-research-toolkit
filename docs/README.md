# 无限法则本地跑图与武器研究版

双击桌面的“无限法则 - 本地跑图”，或游戏目录的 `启动本地人物跑图.cmd`。大厅选择地图和枪械，加载后使用原生人物移动、蹲伏与趴下。默认会话一小时，只连接127.0.0.1:8001。

地图菜单现包含海岛（欧罗巴岛，10019 / EU_KillZone_4096），海岛跑图兼容性处于测试阶段。已在 UserData/CurrentSettings6.xml 开启 HRTF 与声音遮挡，需重启客户端加载。

## 操作与功能

- WASD移动、鼠标转向，C蹲下、Z趴下。
- 靠近支持交互的门，按 F 开关；已由用户实际确认。
- UZI/MSR 本机原枪声节点缺失，暂用 MP5/R700 音效，已完成冷启动音频测试。
- 左键开火；1/2/3切换三个武器槽；R走原生换弹流程并消耗备用弹药，4 秒后检查是否需要本地兜底。
- Esc打开分类菜单，包含地图、枪械、六类配件、弹药、载具、天气、地面交互和选点复活。
- Tab已接入背包动作；真实按键验证尚未完成，可用Esc菜单按钮进入。
- 背包最后一项“地图选点复活”可打开原生地图选位置。
- 选点地图显示自己的黄色位置点；选择出生位置时标记随选择更新。存在真实敌方选点数据时显示蓝方块。
- 开局背包按地图区分：雪山为滑翔、滑雪、登山；海岛为滑翔翼、自行车、钩爪。各地图分别保存选择，选点卡片与实际能力使用同一配置。登山/钩爪的完整场景交互仍待验证。
- 登山背包靠近雪山滑索时显示「使用滑索」，按原版 F 交互，从高处滑向低处；下滑实测约16米/秒，用户已确认正常。
- 武器库列出33把枪，按原生兼容性筛选配件。三个槽位、配件和备用弹药保存在 `offline-research/local-server/local-loadout.json`。
- 载具目录包含 17 种可用车型/船只，支持召唤 1/2/3/4/8 台、驾驶、F 上下车；船只应放在水面。车身显示已经用户确认。
- 衣服自动恢复上衣、裤子和鞋子，保存于 `local-outfit.json`；衣服显示已经用户确认。
- “医疗补给 / 治疗”可使用绷带、医疗包、医疗箱和能量饮料，并补齐库存。9/8/7 分别使用前三种药品；移动、受伤、切枪、开菜单或 F 可中断治疗且不扣药。饮料使用 4 秒后持续回血。
- “投掷物”可选择手榴弹、烟雾弹或闪光弹，参数可选装备/直接高抛/直接轻抛。5 取出上次选择，左键高抛、右键轻抛，1/2/3 返回枪械。库存保存于 `local-consumables.json`。原生实体与轨迹已验证，完整动作和范围伤害仍待补齐。
- “地面交互 / 拾取”可在脚边生成本地补给点，看原版交互 HUD 提示按 F 拾取；弹药入账，枪械装备，配件自动寻找兼容的随身枪。可清空本地图拾取点，换图自动清理。**地面物品模型尚未显示**，不是全地图原版刷物资。

六把代表枪械已通过原生开火/扣弹集成验证：M4A1、MP5、USP45、雷明顿870、雷明顿700、沙漠之鹰。五种配件安装、拒绝不兼容瞄具、扩容40发与默认30发均有记录。不是全部33把枪逐一验证。
